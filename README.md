# Нұрым & Карина — үйлену тойына шақыру

Одностраничный пригласительный сайт на казахском языке (мобильная колонка 430px, по центру на десктопе). Статика без сборки: `index.html` + `assets/`.

- **Дата:** 12.09.2026, 18:00 (Астана, UTC+5)
- **Место:** Dilu Plaza, 1 этаж, Астана ([2GIS](https://2gis.kz/astana/search/Dilu%20plaza/firm/70000001055312155/71.347903%2C51.146402))
- **Той иелері:** Ғалымжан & Мейрамгүл

## Секции

1. **Hero** — фото, виниловая пластинка-кнопка музыки, имена рукописным шрифтом
2. **Шақыру** — «Құрметті қонақтар!» с акварельными цветами
3. **Той салтанаты** — зелёная карточка: дата, календарь сентября с рисующимся сердцем на 12, время начала, той иелері
4. **Мекенжай** — адрес + кнопка «Карта» (2GIS)
5. **RSVP** — имя + Келемін / Жұбыммен келемін / Қатыса алмаймын, ответ уходит в WhatsApp (+7 702 487 04 85)
6. **Тойға дейін** — живой обратный отсчёт, цветочный бордюр

## Музыка

`assets/music.mp3` — автозапуск при загрузке с отметки **2:05** (мобильные браузеры блокируют автоплей со звуком — тогда песня стартует при первом касании экрана). Зацикливается обратно на 2:05. Пауза/плей — по клику на винил.

## Шрифты

Bad Script + Montserrat (Google Fonts) — проверены на полную поддержку казахской кириллицы (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, І).
