# Карина & Нұрым — үйлену тойына шақыру

Одностраничный пригласительный сайт на казахском языке. Один самодостаточный файл `index.html` — без сборки и зависимостей.

- **Дата:** 12.09.2026, 18:00 (Астана, UTC+5)
- **Место:** Dilu Plaza, 1 этаж, Астана ([2GIS](https://2gis.kz/astana/search/Dilu%20plaza/firm/70000001055312155/71.347903%2C51.146402))
- **Той иелері:** Ғалымжан & Мейрамгүл

## Что внутри

- Hero с поочерёдным появлением имён и сердечками в дате
- Приглашение с казахским орнаментом (қошқар мүйіз) в качестве разделителей
- Календарь сентября 2026 — сердце рисуется вокруг даты 12 и «бьётся»
- Живой обратный отсчёт до начала тоя
- Секция локации с кнопкой 2GIS
- Летающие золотые частицы, зерно плёнки, scroll-reveal анимации
- Шрифты: Cormorant + Montserrat (оба с поддержкой казахской кириллицы: Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, І)
- Уважает `prefers-reduced-motion`

## Локальный просмотр

```bash
python3 -m http.server 8741
# открыть http://localhost:8741
```

(Можно и просто открыть `index.html` двойным кликом — шрифты подтянутся из Google Fonts.)

## Деплой на Vercel

```bash
npx vercel --prod
```

Или перетащить папку на [vercel.com/new](https://vercel.com/new) — статический сайт, настройки не нужны.
